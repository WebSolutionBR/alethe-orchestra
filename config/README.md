# Configuration snapshot (sanitized)

Configuration that the Alethe Orchestra app and its Claude Code agents used on the owner's PC,
captured on 2026-10-05 for reference and for setting up another machine. **Nothing here is a
credential.** Every token, key and secret was masked or left out, as listed below. None of these
files is read by the app from this folder: copy what you need to the original location by hand.

## What is here

| File | Origin on the PC | Changes |

| `claude/mcp-servers.sanitized.json` | the `mcpServers` block of each account's `.claude.json` (identical in the four accounts) | Every `env` value masked as `<masked>`; only the server definitions were copied. |

### App preferences

`projects.json` held no token: `spotifyClientSecret` and `spotifyClientId` were already empty,
and the Claude accounts are stored as id, name and creation time only. Still masked:

- `preferences.profileImageUrl`: the base64 profile picture (about 1 MB), replaced by a placeholder;
- `tabs[].sessionId` (7): Claude Code conversation ids used by `claude --resume`.

The structure, paths, layout and every other preference are unchanged.

## What was deliberately left out

- `.credentials.json` of every account (OAuth tokens);
- `.claude.json` as a whole (OAuth account, user id, caches, per-project history); only the
  `mcpServers` block was extracted, masked;
- conversation transcripts (`*.jsonl`), `history.jsonl`, `file-history`, `paste-cache`,
  `shell-snapshots`, `session-env`, `sessions`, `cache`, `backups` and `plugins`;
- `skills/synced/`: copies of the skills synced from claude.ai (not specific to the Orchestra, and
  some of them carry client work content). No account has its own `agents/`, `commands/` or
  `CLAUDE.md`;
- the Obsidian Local REST API key, the Hostinger API token, the Speak AI key and the GitHub
  token: none of them appears in this repository (checked against the real values before each
  commit).

## Line endings

`.gitattributes` keeps `orch.cmd` in CRLF (a batch file) and the `orch` sh shim in LF, as the app
writes them.
